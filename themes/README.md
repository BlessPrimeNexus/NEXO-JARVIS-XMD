# Thèmes du bot

Chaque dossier `themes/<nom>/` est un thème : déposez-y des images `.jpg` / `.png`
(1200×630 conseillé). Il apparaît automatiquement dans la commande `.theme`.

Thèmes fournis : escanor, jinwoo, spiderman, zerotwo, gojo, sakura (images originales à l'ambiance de chaque univers).
Le thème « Jarvis » (par défaut) utilise le dossier `jarvis-images/`.

Pour des images de personnages, utilisez des visuels dont vous avez les droits.
