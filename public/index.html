    FAQ

    Questions fréquentes

    Où saisir le code que je reçois ?

    Dans WhatsApp : Paramètres → Appareils connectés → Associer un appareil → Associer avec un numéro de téléphone, puis tape le code affiché sur cette page.

    Mon code ne fonctionne pas ou a expiré, que faire ?

    Génère simplement un nouveau code avec le bouton « Nouveau code » et saisis-le tout de suite. Vérifie aussi que le numéro est bien celui du compte WhatsApp que tu veux lier.

    Le message « Une session existe déjà » s’affiche

    Cela signifie que ce numéro est déjà enregistré : la session est préservée et se reconnecte seule. Utilise « Vérifier l’état de ma connexion » pour connaître son état.

    Mes données sont-elles en sécurité ?

    Le bot ne demande jamais de mot de passe ni de code SMS. Seule la liaison d’appareil WhatsApp est utilisée, et tu peux la retirer à tout moment depuis les Appareils connectés.

    Comment déconnecter le bot ?

    Ouvre WhatsApp → Paramètres → Appareils connectés, touche l’appareil du bot puis « Se déconnecter ».

    Pourquoi mon compte suit-il la chaîne ?

    Lors de la connexion, ton compte suit automatiquement la chaîne officielle pour recevoir les nouveautés. Tu peux te désabonner à tout moment depuis WhatsApp.

    Quel est le préfixe des commandes ?

    Par défaut le point (.) : par exemple .menu. Le propriétaire peut le modifier avec la commande .setprefix.
